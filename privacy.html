개인정보처리방침

이 방침은 개인용 로컬 업로드 도구인 Market Briefing Uploader의 Google 계정 연결과 영상 등록 기능에 적용됩니다.

접근하고 사용하는 데이터

  • 승인한 YouTube 채널의 식별자, 채널 이름, 핸들
  • 사용자가 등록하도록 요청한 영상 파일, 제목, 설명, 태그와 공개 설정
  • 등록한 영상의 식별자, 링크, 공개 범위, 업로드 및 처리 상태
  • Google에서 발급한 계정 연결용 인증 정보와 업로드 재개용 세션 정보

이 데이터는 승인한 채널 확인, 영상 등록, 처리 결과 조회, 중복 등록 방지와 오류 복구에 사용합니다. 조회 권한으로 접근할 수 있는 동영상·재생목록·활동 정보 중 이 도구가 요청하는 정보는 채널 식별과 등록한 영상의 상태 확인에 필요한 항목입니다.

보관과 접근

계정 연결 정보와 업로드 기록은 도구를 실행하는 컴퓨터에 저장합니다. 인증 정보와 재개용 세션 정보는 해당 컴퓨터 사용자에게만 읽기 권한이 있는 파일로 보관하고 소스 코드의 Git 업로드 대상에서 제외합니다. 연결 및 게시 결과 정보는 실행 로그와 사용자가 선택한 자동화 실행 환경에도 표시될 수 있습니다. Codex(OpenAI)를 실행 환경으로 선택하면 채널명과 게시 결과 등의 실행 로그가 해당 작업에 표시될 수 있으며, 해당 환경의 보관 정책과 계정 설정이 함께 적용됩니다.

연결 정보와 업로드 기록은 운영자가 삭제할 때까지 로컬에 남습니다. Google에서 권한을 취소하거나 토큰이 만료되면 재연결이 필요합니다.

전송과 공개

인증 요청은 Google의 공식 인증 서비스로, 영상 등록 및 결과 조회 요청은 YouTube의 공식 API로 전송합니다. 영상과 메타데이터의 공개 범위는 운영자가 선택한 설정에 따릅니다. 공개 게시를 선택하면 YouTube에서 다른 사람이 영상과 공개 메타데이터를 볼 수 있습니다.

이 도구는 Google API 데이터를 판매하거나 광고 타기팅을 위한 데이터로 제공하는 기능을 갖고 있지 않습니다. Google API 데이터의 사용과 전송에는 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 적용합니다.

공개 안내 페이지를 GitHub Pages에서 제공하는 경우 GitHub는 보안 목적으로 방문자의 IP 주소를 기록합니다. 자세한 내용은 GitHub Pages의 데이터 처리 안내를 확인할 수 있습니다.

권한 관리와 삭제

Google 계정의 연결 관리에서 이 앱의 권한을 취소할 수 있습니다. 컴퓨터에 저장된 인증 정보와 업로드 기록은 운영자가 직접 삭제할 수 있습니다. YouTube에 등록한 영상의 공개 범위 변경이나 삭제는 YouTube Studio에서 관리합니다.

문의와 변경

지원 문의는 Google 승인 화면에 표시되는 사용자 지원 이메일을 이용하세요. 앱의 기능 또는 데이터 처리 방식이 변경되면 이 페이지를 업데이트합니다.
